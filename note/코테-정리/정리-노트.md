# 정리 노트

## 코테에서 배열 사용 방식
1. 수열 저장할 때
- 피보나치

2. 무언가 체크할때
- 출석한 학생 
-> 배열 총합
-> 0의 리스트를 학급 수만큼 만들고 출석하면 해당 index값을 1로 변경 

- 아직 출석 하지 않은사람 
-> index 0인 사람

3. 무언가 카운트 할 때
- 학급반장 선거
-> 반복해서 들어오는 값에 인덱스를 계속 더해줌
-> 첫번째, 두번째 카운트 계산
